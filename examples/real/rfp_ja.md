社内経費精算システム 要件定義書(案) v0.3
作成: 情シス 2026/09/12 ※社外秘

1. 概要
　従業員が交通費・立替経費を申請し、上長が承認、経理が月次で会計システム(SAP)へ連携する。現行はExcelとメール。

2. 機能要件
| No | 機能 | 内容 | 優先度 |
|----|------|------|--------|
| F-1 | 申請 | 従業員は経費(日付、金額、費目、領収書画像)を申請できること。 | 必須 |
| F-2 | 承認 | 上長は申請を承認・差し戻しできること。5万円以上は部長承認も必要。 | 必須 |
| F-3 | 一覧 | 経理は月ごとの申請一覧を検索・CSV出力できること。 | 必須 |
| F-4 | 連携 | 承認済み申請を毎月1日にSAPへ連携すること(CSVをSFTPで配置)。 | 必須 |
| F-5 | 通知 | 承認・差し戻し時に申請者へメール通知すること。 | 推奨 |
| F-6 | OCR | 領収書画像から金額を自動読み取り(TBD) | 任意 |

3. 非機能要件
3.1 性能: 一覧検索は 2 秒以内に応答すること(データ 10 万件時)。
3.2 可用性: 平日 8:00〜20:00 は稼働率 99.5% 以上。
3.3 セキュリティ: 領収書画像・個人情報は暗号化して保存。監査ログを 7 年保持。
3.4 同時利用: 月末はピークで同時 300 ユーザー。

4. 制約
- 社内認証は Azure AD(OIDC)。
- 既存の Oracle DB は使わず、新規に PostgreSQL を採用予定。
- 開発ベンダー 4 名+社内 1 名。2027 年 3 月リリース。
- Azure 上のコンテナ(AKS)で稼働。

5. 対象外
- 給与計算、旅費規程の自動判定。
