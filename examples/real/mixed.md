# 予約管理 SaaS(美容室向け)

## やりたいこと
- [ ] 店舗オーナーは店舗・スタッフ・メニュー(所要時間・価格)を登録できる
- [ ] お客様は Web から空き枠を検索して予約できる(会員登録なしでも可、メール認証)
  - 予約確定時に SMS と email で通知
  - 前日 18:00 にリマインド SMS
  - キャンセルは 2 時間前まで
- [ ] スタッフは当日の予約一覧をスマホで見られる
- [ ] オーナーは月次の売上レポート(PDF)をダウンロードできる
- [x] 決済は当面 現地払いのみ(Stripe は将来)

## 数字
- 店舗 500、1 店舗あたり予約 30 件/日
- 空き枠検索は p95 で 800ms 以内
- 予約のダブルブッキングは絶対に起こしてはならない

## 技術
- Ruby on Rails 7 / PostgreSQL / Redis / Heroku、開発 2 名(業務委託)
- SMS は Twilio
- 個人情報(電話番号)は暗号化して保存すること

## やらないこと
- POS 連携、在庫管理
