# 倉庫在庫管理サービス

倉庫スタッフが在庫の入出庫を記録し、マネージャーが欠品を把握するためのサービス。

## 機能要件
- スタッフは在庫品目(SKU、数量、倉庫、棚)を REST API で追加・移動・削除できる。
- マネージャーは在庫が発注点を下回るとメールで通知される。
- マネージャーは在庫一覧を CSV でエクスポートできる。
- 利用者は SKU と倉庫で在庫を検索できる。

## 非機能要件
- 検索は 20万件の品目に対して 300ms以内(p95)に応答すること。
- 在庫数は同時更新でも失われず、二重に適用されない。
- 月間稼働率 99.9% 以上。
- Prometheus 向けメトリクスと構造化ログを出力する。

## 制約
- TypeScript(Node 20)。PostgreSQL を利用可能。チームは 2 名。
- コンテナで既存のイングレスの背後で動かす。

## 対象外
- 購買・仕入先管理。
