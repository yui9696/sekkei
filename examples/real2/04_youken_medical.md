# 在宅患者モニタリングシステム 要件定義書(第1.2版)

## 1. 目的
在宅療養中の患者に貸与する血圧計・パルスオキシメータ・体重計(以下「機器」)の測定値を自動収集し、訪問看護ステーションの看護師と主治医が異常を早期に把握できるようにすること。

## 2. 用語
| 用語 | 定義 |
|---|---|
| 機器 | Bluetooth Low Energy 対応の医療機器(薬機法上のクラスⅡ) |
| ゲートウェイ | 患者宅に設置する小型端末。機器の測定値を受信しクラウドへ送信する |
| 閾値 | 主治医が患者ごとに設定する異常判定の上限・下限 |

## 3. 機能要件
| No. | 要件 | 区分 |
|---|---|---|
| F-1 | 機器で測定した値を、ゲートウェイ経由で測定後5分以内にクラウドへ送信すること。 | 必須 |
| F-2 | ゲートウェイが通信不能の場合、測定値を最大72時間保持し、復旧後に送信すること。 | 必須 |
| F-3 | 看護師は担当患者の測定値を時系列グラフで閲覧できること。 | 必須 |
| F-4 | 主治医は患者ごとに閾値を設定・変更できること。変更は即時反映すること。 | 必須 |
| F-5 | 測定値が閾値を超えた場合、担当看護師へ3分以内にプッシュ通知および SMS で通知すること。 | 必須 |
| F-6 | 看護師は通知を確認済みにでき、確認されない通知は30分後に管理者へエスカレーションすること。 | 必須 |
| F-7 | 主治医は所見を記録でき、記録は電子カルテ(既存の Medi-Chart)へ夜間バッチで連携すること。 | 必須 |
| F-8 | 患者本人は自身の測定値をスマートフォンアプリで閲覧できること。 | 任意 |
| F-9 | 管理者は機器の貸与・返却を登録し、機器の稼働状況を一覧できること。 | 必須 |

## 4. 非機能要件
- 同時接続するゲートウェイは初年度で1,500台、3年後に10,000台とすること。
- 測定値の保存期間は5年とすること(医療法に準拠)。
- 測定値は改ざん不可であること。修正が必要な場合は訂正履歴を残すこと。
- 稼働率は99.9%以上とすること。ただし計画停止は月1回2時間まで認める。
- 個人情報は暗号化して保存し、アクセスログを3年間保持すること。
- 画面は日本語のみとする。
- クラウドは国内リージョンに限定すること。

## 5. 制約
- 開発チームは4名。既存システムは Ruby on Rails で構築されており、同一技術を優先すること。
- 機器メーカーの SDK は Android のみ提供されるため、ゲートウェイは Android 端末とする。
- 初回リリースは2027年3月末とすること。
