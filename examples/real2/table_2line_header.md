# Parking Permit System

| ID | Requirement | Prio- |
|    |             | rity  |
|---|---|---|
| P-1 | Residents must apply for a permit online and pay by card. | Must |
| P-2 | Wardens must verify a plate in under 2 seconds via the mobile app. | Must |
| P-3 | Permits expire after 12 months and residents are reminded 30 days before. | Should |
| P-4 | 50,000 permits; 200 verifications/minute at peak. | Must |

Team of 3, Python, PostgreSQL available.
